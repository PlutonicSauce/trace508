# Trace508 threat model

Date: 2026-10-17. Protected assets: assessment content, screenshots/DOM, reviewer identity/history, report claims, database credentials, AI keys and trusted target policy.

| Actor / entry | Threat | Implemented mitigation | Residual risk / verification |
|---|---|---|---|
| Unauthenticated first visitor / setup | Administrator takeover, adoption of legacy evidence | Operator-issued hashed bootstrap, expiry, persistent completion, transaction lock, explicit legacy adoption | Clean/concurrent/initialized/legacy database tests; trusted operator and host remain security boundaries |
| Password attacker / login | Guessing, hash resource exhaustion, stolen cookies | Argon2id, per-account throttle, hashing concurrency cap, hashed sessions, HttpOnly/Secure/SameSite, revocation | No MFA/SSO/email assurance, small blocklist, distributed throttling not proven |
| Organization member / resource IDs | IDOR, foreign downloads or forged review identity | Server project/organization guards, role checks, server actor identity | Deterministic cross-organization and role tests; DB operators trusted; no row-level database tenant policy |
| Malicious website / Chromium | SSRF, metadata access, DNS rebinding, redirects, file protocols, browser escape | HTTPS allowlist, all-answer DNS validation/pinning, request routes, bounded contexts and budgets; separate-browser Compose topology | Native process is not a sandbox against browser exploits; container network, seccomp filtering, and Linux sandbox gates verified in remote CI test environment (runs `39099390432`, `39161558167`) |
| Malicious page / report or UI | Stored XSS, prompt injection, invented compliance | React escaping, CSP, bounded structured AI IDs, no AI conformance write path, human report gate | Inline CSP exceptions, no complete penetration test or assistive technology certification |
| Worker crash / queue | False completion, duplicate observations, stuck jobs | Atomic leased claim, DB heartbeat, terminal failure recovery, immutable attempts, bounded explicit retry, request idempotency, supervisor | Interrupted jobs may take 3 minutes to fail; supervisor recovery verified in worker fault tests; container restart verified in CI |
| Storage operator / packages | Source tampering, invalid screenshot/report bytes | Canonical/source hashes, byte checks on export/download, independent manifest and archive digest | No signatures/write-once storage; trusted digests and backup custody necessary |
| Operator error / deletion | Evidence loss, orphan files, unbounded accumulation | Typed deletion, retention dry-run, per-project/server admission quotas, state/source/archive caps, audit events | DB/filesystem deletion not atomic; backups/retention/host free-space monitoring required; quota is not a kernel disk quota |
| AI service / optional inference | Data disclosure, billed calls, fabricated observations | Default disabled; local Ollama option; cloud server opt-in + admin consent; minimized payload; strict schema/IDs, no fallback | Live local model unavailability is separate from contract tests; cloud free-tier billing not technically guaranteed |
| Deployment / secrets | Public PostgreSQL, stolen environment or TLS failure | No published DB/browser/egress/worker ports; secret files; nonroot/read-only/drop-caps/resource limits; HTTPS proxy | Test-container startup/loopback TLS/secrets/network verified in CI; public production TLS, enterprise SSO/MFA, and federal ATO/FedRAMP remain open production requirements |

Trust boundaries: browser content → browser network; browser protocol → worker; API/session → project-scoped DB; protected artifacts → authorized download; server → optional AI; operator → bootstrap/recovery/backup. Compose separates browser, data and frontend networks; isolation verified via verify-container-security.py in CI runner.

Adversarial checks only target isolated controlled fixtures and the isolated test database. Public W3C/example.com activity is ordinary scoped accessibility scanning, not intrusive security testing.
